# Decoration icons

PNG files here are registered as ModTek Sprites / Texture2D.

Filename (without extension) must match the catalog `icon` field and any event `Icon` id, e.g.:

- `decoration_Mercenary_RagingWasp.png`
- `decoration_Davion_FederatedSunsMedalofHonor.png`
- `decoration_Davion_OperationRATServiceRibbon.png`

Preferred size: 512×512 (or matching your other UI medals).
